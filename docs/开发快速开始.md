# 知枢 · 开发快速开始

> 进度总览见 [开发进度.md](./开发进度.md) ｜ 前端 SFC 约定见 [前端约定.md](./前端约定.md)

## 前置

- Python 3.12+
- Node.js 20+
- （可选）Docker Desktop：有则用 PostgreSQL+pgvector；**无 Docker 时默认 SQLite stub**

## 一键启动（推荐）

在仓库根目录任选其一：

| 方式 | 操作 |
|------|------|
| 双击 | `start.bat` |
| PowerShell | `.\scripts\start.ps1` |

脚本会：生成 `.env`（若不存在）→ 创建/复用 `server\.venv` 并装依赖 → 装前端依赖 → 释放 8000/5173 → 各开一个窗口跑 API 与 Vite → 打开浏览器登录页。

停止：双击 `stop.bat`，或 `.\scripts\stop.ps1`，或直接关掉两个服务窗口。

| 地址 | 说明 |
|------|------|
| http://127.0.0.1:5173 | 前端 |
| http://127.0.0.1:8000 | API /docs |
| `admin` / `admin123` | 管理员（密级 L4）· 默认工作区 + 制度隔离区 · 可进审计 |
| `member` / `member123` | 普通成员（密级 L2）· 仅默认工作区 |

顶栏可切换工作区。建议路径：

1. 登录 →「知识库」上传 `fixtures/travel_policy.md`  
2. 「问答」点欢迎页推荐问题或自问  
3. 点回答里的「参考来源」看右侧原文  
4. admin：「知识库」改密级 / 有效期；「审计」查看与导出日志  

## 手动启动（Windows / 无 Docker）

```powershell
Copy-Item .env.example .env
python -m venv server\.venv
.\server\.venv\Scripts\Activate.ps1
pip install -r server\requirements.txt

$env:PYTHONPATH="server"
python -m uvicorn app.main:app --app-dir server --reload --host 127.0.0.1 --port 8000

# 另开终端
cd frontend
npm install
npm run dev
```

有 Docker 时可将 `.env` 中 `USE_SQLITE=false`，并执行 `docker compose -f deploy/docker-compose.yml up -d`。

## stub 与正式模式

| 模式 | `ZHISHU_DEV_STUB` | 行为 |
|------|-------------------|------|
| 开发 stub | `1` | 本地 PDF/DOCX/MD 解析；伪嵌入 + 关键词检索；模板回答 |
| 正式 | `0` | 调 TEI / llama-server /（可选）Docling HTTP |

问答推理渠道在管理台 **设置**（admin）：DeepSeek（填 Key）/ Ollama / llama.cpp / Stub。  
选 Ollama 或 llama.cpp 时可「拉取模型列表」。嵌入/重排仍受 `ZHISHU_DEV_STUB` 影响。

## 冒烟

```powershell
.\server\.venv\Scripts\python scripts\smoke.py
```

覆盖：JWT 登录、SSE 引用、L2 看不到 L4、跨工作区隔离、非成员 403、**过期文档不可检索**、审计写入。
