# 知枢 · 备份与恢复（C-202）

## stub / 单机（SQLite）

| 动作 | 命令 |
|------|------|
| 备份 | `powershell -File scripts\backup.ps1` |
| 带标签 | `powershell -File scripts\backup.ps1 -Tag nightly` |
| 演练取证 | `server\.venv\Scripts\python scripts\backup_drill.py` |
| 恢复 | 先 `.\scripts\stop.ps1`，再 `powershell -File scripts\restore.ps1 -BackupDir data\backups\<stamp>` |

备份落在 `data/backups/<yyyyMMdd-HHmmss>/`：

- `zhishu.db`（优先 SQLite online backup API）
- `files/`（原始上传）
- `manifest.json`

恢复前会把现网库拷到 `data/pre-restore-*` 兜底。

## 正式（PostgreSQL）

```text
pg_dump -Fc -f zhishu.dump "$DATABASE_URL"
# files 卷：rsync / 卷快照
pg_restore -d "$DATABASE_URL" --clean --if-exists zhishu.dump
```

Compose 卷名见 `deploy/docker-compose.yml`（`pg_data`、`files`）。
