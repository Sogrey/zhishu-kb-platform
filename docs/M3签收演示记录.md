## 4. 演示路径（给人看的 15 分钟）

1. **登录** admin → 顶栏确认工作区「默认工作区」  
2. **知识库**：拖入 `fixtures/expense_grades.md` → 分块见「表格」  
3. **问答**：问「P4 住宿上限一线」→ 回答含整表；点参考来源  
4. **密级**：把某文档调 L4 → member 登录不可见；admin 可见  
5. **有效期**：文档改 `valid_to` 到过去 → Hit Test 不再命中  
6. **归并**：上传近似 v2 → 治理/知识库确认归并 → 旧稿标历史稿  
7. **审计**：治理 → 审计 → 导出 JSON/CSV  
8. **Hit Test**：治理 → Hit Test → 跑问题看注入全文  
9. **水印**：L3+ 文档开分块 → 见「用户·时间·知枢保密」  
10. **评测**：治理 → 评测 → 看板趋势 → 运行（或夜间）→ 见四指标与 `engine`  
11. **Trace**：问答后点助手「Trace」→ 见 retrieve / inject / generate 耗时；可跳转关联 Hit Test

一键取证（可重复）：

```powershell
server\.venv\Scripts\python.exe scripts\m3_accept.py
```
