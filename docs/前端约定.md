# 知枢 · 前端约定

## SFC 块顺序（强制）

所有 `.vue` 单文件组件按以下顺序书写：

1. **`<template>`**
2. **`<script setup lang="ts">`**
3. **`<style lang="less" scoped>`**

不要使用 `script` 在前的旧顺序；样式统一 **Less**（Vite 已装 `less` 预处理器）。

示例骨架：

```vue
<template>
  <div class="wrap">…</div>
</template>

<script setup lang="ts">
/** 组件职责说明 */
</script>

<style lang="less" scoped>
.wrap {
  color: var(--zs-ink);
  &:hover {
    opacity: 0.9;
  }
}
</style>
```

## 模块拆分

| 目录 | 说明 |
|------|------|
| `src/modules/chat/` | 问答：`ChatView` 编排 + `useChatSession` + 子组件 |
| `src/modules/knowledge/` | 知识库 |
| `src/modules/governance/` | 治理中枢 + Hit Test / 审计 / **评测 EvalView** |
| `src/modules/auth/` | 登录 |
| `src/modules/settings/` | 管理员设置（LLM 三渠道） |
| `src/api/` | `client.ts` 请求；`types.ts` DTO |
| `src/shared/` | 鉴权、Markdown、**DynamicWatermark（L3+）**、密级工具 |

问答页文件：

- `ChatView.vue` — 三栏布局编排（薄）
- `useChatSession.ts` — 会话 / SSE 状态
- `ChatHistoryAside.vue` / `ChatWelcome.vue` / `ChatThread.vue` / `ChatComposer.vue` / `CitationRail.vue`
- `samples.ts` / `types.ts`

## 样式

- 设计令牌在 `src/styles/tokens.css`（CSS 变量 `--zs-*`）
- 组件内优先 Less 嵌套；避免再引入全局 CSS 框架覆盖
